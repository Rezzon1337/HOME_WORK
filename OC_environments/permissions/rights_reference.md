# Права доступа: символьная и восьмеричная формы

Права символами состоят из 10 знаков: `[тип][владелец][группа][прочие]`. Тип: `-` (файл), `d` (каталог), `l` (символическая ссылка). Остальные три тройки содержат `rwx` или `-`.

| Пример `ls -l` | Восьмеричный код | Комментарий |
|---|---:|---|
| `-rw-------` | `600` | только владелец читает и пишет |
| `-rw-r-----` | `640` | группа может читать |
| `-rw-r--r--` | `644` | типичный режим обычного документа |
| `-rwxr-xr-x` | `755` | исполняемый файл / каталог с проходом для всех |
| `-rwxr-xr--` | `754` | группа исполняет, другие только читают |
| `drwx------` | `700` | закрытая папка владельца |
| `drwxrwxrwt` | `1777` | всем можно создавать записи; sticky-bit ограничивает удаление чужих файлов |

Числа 4, 2, 1 отвечают за чтение, запись и исполнение. Для символических ссылок `lrwxrwxrwx` часто показывает фиктивный режим самой ссылки: доступ определяется её целью и каталогами. ACL могут вводить дополнительные права, которые не полностью выражаются простой тройкой `rwx` (`getfacl` для просмотра).

Показать права каждого выбранного файла можно скриптом `permissions/inspect_permissions.sh /etc/passwd /etc/hosts`. У всех реальных файлов ОС единого фиксированного режима нет: результат следует снять именно с вашей VM.
