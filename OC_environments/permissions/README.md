# Задания по пользователям, владельцам и правам

Источники: `линукс.txt` и слайд 42 из `ОС Админ linux.pptx`. **Этот сценарий требует прав root и действительно изменяет систему. Выполнять ТОЛЬКО на выделенной учебной виртуальной машине после создания snapshot.** Он создаёт 3 локальных пользователя и лабораторные файлы под `/srv/linux-homework-users`. Скрипт НЕ следует запускать на рабочем сервере.

## Выполнение

```bash
sudo bash permissions/user_lab.sh
sudo ls -la /srv/linux-homework-users
sudo stat -c '%n %U:%G %a %A' /srv/linux-homework-users/*
./permissions/inspect_permissions.sh /etc/passwd /etc/hosts
```

Демонстрационные учётные записи `hw_alice`, `hw_bob`, `hw_carol`. Каждый создаёт один файл, после чего root переназначает владельца на *другого* пользователя:

| Имя файла | Кто создал | Итоговый владелец | Код | Символьные права | Значение |
|---|---|---|---|---|---|
| `alice.txt` | hw_alice | hw_bob | `600` | `-rw-------` | чтение/запись владельцу |
| `bob.txt` | hw_bob | hw_carol | `640` | `-rw-r-----` | чтение/запись владельцу, чтение группе |
| `carol.txt` | hw_carol | hw_alice | `754` | `-rwxr-xr--` | все владельцу, чтение+исполнение группе, чтение прочим |

Число составляется суммой битов: `r=4`, `w=2`, `x=1`. Пример: `rwx=7`, `r-x=5`, `r--=4`, значит `754`.

Важно: доступ к файлу зависит также от прав на **все родительские каталоги**. Скрипт создаёт отдельный тестовый каталог с `1777` — запись для всех со sticky-bit (аналог `/tmp`); это сделано, чтобы пользователи действительно могли изначально создать файлы. Нельзя использовать такие права для чувствительных данных. При `chown` итоговые разрешения проверяются уже у назначенных владельцев.

## Проверка фактического доступа

```bash
sudo -u hw_bob cat /srv/linux-homework-users/alice.txt     # работает, hw_bob владелец
sudo -u hw_alice cat /srv/linux-homework-users/alice.txt   # запрещено (600)
sudo -u hw_alice cat /srv/linux-homework-users/carol.txt   # работает, hw_alice владелец
stat -c '%a %A %U:%G %n' /etc/passwd /etc/hosts
```

## Чек-лист скриншотов для сдачи

1. `id hw_alice; id hw_bob; id hw_carol` — показать существование учётных записей.
2. `ls -l /srv/linux-homework-users` — показать три разных режима и новые имена владельцев.
3. `stat -c '%n %U:%G %a %A' /srv/linux-homework-users/*` — цифровые значения прав.
4. Результаты чтения под разными пользователями (успех/отказ).

Скриншоты своей учебной VM сохранять в `evidence/vm/`. Если работа выполняется на чужом сервере, проверьте разрешение администратора перед созданием учётных записей.
