# Установка Debian в Oracle VirtualBox: инструкция

Это пошаговая **инструкция**, а не утверждение, что установка уже выполнена на компьютере автора. Для фактического подтверждения установки нужны скриншоты работающей гостевой ОС.

## 1. Подготовка

1. Проверить, что аппаратная виртуализация разрешена (Intel VT-x / AMD-V) и компьютер располагает ресурсами.
2. Скачать VirtualBox с официального сайта: <https://www.virtualbox.org/wiki/Downloads>.
3. Скачать ISO с официальной страницы Debian: <https://www.debian.org/distrib/>; для типового x86-64 ПК — `amd64 netinst` (понадобится доступ к сети) или DVD-образ.
4. Проверить SHA256 скачанного ISO по контрольным суммам Debian. В Windows можно выполнить `certutil -hashfile file.iso SHA256`, в Linux — `sha256sum file.iso`; сравнить с официальной записью для точно этого файла.

## 2. Создать виртуальную машину

1. В VirtualBox нажать **New / Создать** и указать имя `Debian-Lab`, тип Linux, версию Debian (64-bit).
2. Выбрать скачанный ISO как установочный диск. При необходимости отключить unattended installation для ручного прохождения установщика.
3. Пример параметров для учебной VM: **2 виртуальных процессора**, **2–4 ГиБ ОЗУ**, **25–30 ГиБ динамического VDI**. Это рекомендованные для упражнения значения, а не системные минимумы Debian; не выделять больше ресурсов, чем доступно хосту.
4. Сеть: NAT — простой режим для скачивания пакетов. Режим «Сетевой мост» включать только при необходимости и понимании сетевого доступа.
5. Запустить VM. Если 64-bit гостевая система недоступна, проверить поддержку виртуализации и настройки гипервизора хоста.

## 3. Установить Debian

1. Выбрать `Graphical install` (или текстовый `Install`).
2. Указать язык, регион и раскладку клавиатуры; настроить имя машины.
3. Создать обычную учётную запись и надёжный пароль. При выборе подхода с отдельным root следовать подсказкам установщика; на Debian sudo для первого пользователя зависит от способа настройки root.
4. Разметка диска: для учебной VM удобно `Guided — use entire disk`, выбрать **виртуальный диск** VM, а не реальный диск компьютера. Установщик создаст разделы; для минимального лабораторного варианта можно поместить все файлы в один раздел. Альтернатива — ручная разметка с корневым `/` и, по желанию, отдельным `/home`.
5. Установить базовую систему. По желанию выбрать графическую среду (например, GNOME) и SSH-сервер.
6. Установить загрузчик GRUB на виртуальный диск. Перезагрузить VM и извлечь ISO из виртуального оптического привода, если это необходимо.

## 4. Проверить установку

После входа в гостевую ОС выполнить:

```bash
cat /etc/os-release
uname -r
id
pwd
ls -la /home
lsblk
ip -br a
```

Сохранить реальные снимки экрана VirtualBox с итогами этих команд в `evidence/vm/`. Не публиковать пароли, токены и личные данные.

## 5. Что такое снимок виртуальной машины (snapshot)

**Снимок** фиксирует состояние виртуальной машины в определённый момент: структуру её виртуальных дисков и, в зависимости от состояния машины и способа создания, сохранённое состояние памяти/VM. Позволяет откатиться к старой точке перед опасными экспериментами, например перед `useradd`, `chown` или обновлением системы.

**Создание:** в VirtualBox Manager выбрать VM → `Snapshots / Снимки` → `Take / Создать`, назвать `01-Clean-install`. Для запущенной VM можно использовать `Machine → Take Snapshot` (расположение зависит от версии). Для **восстановления** остановить VM при необходимости, выбрать снимок и нажать `Restore` — текущие изменения после точки снимка могут быть утрачены. Снимок **не заменяет резервную копию**: его файлы зависят от целостности цепочки виртуальных дисков.

Рекомендуемая последовательность: `01-Clean-install` → `02-Before-users` → `03-Before-memory-lab`. Не удалять файлы снимков напрямую из файлового менеджера — использовать интерфейс VirtualBox.
