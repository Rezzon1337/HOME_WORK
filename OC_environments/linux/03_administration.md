# Основы администрирования Linux

По презентации «ОС Админ linux.pptx». Материал дополняет практическую работу с пользователями и правами из `permissions/`.

## Учётные записи и процессы

Каждый пользователь идентифицируется UID, каждая группа — GID. Root имеет UID 0 и может выполнять административные операции. Учётные записи записаны в `/etc/passwd`, хэши паролей хранятся в `/etc/shadow`; группы — в `/etc/group`. `id`, `whoami`, `groups`, `getent passwd username` позволяют проверить данные. `su - user` переключает пользователя, `sudo command` запускает команду с разрешёнными повышенными правами.

```bash
id
whoami
getent passwd "$(id -un)"
ls -l /etc/passwd /etc/shadow
```

## Права

Строка `-rwxr-xr--` означает: `-` — обычный файл; `rwx` — владелец (7), `r-x` — группа (5), `r--` — прочие (4), код `754`. Для каталогов `x` означает проход по пути, `r` — просмотр списка имён, `w` совместно с `x` — создание и удаление записей. `chmod 640 file`, `chown user:group file`, `stat -c '%a %A %U:%G' file`.

## Мониторинг

`df -h` — использование файловых систем; `du -sh path` — размер дерева каталогов; `free -h` — память; `vmstat 1 3` — системные показатели; `w` — кто подключён и нагрузка; `top`/`htop` — процессы; `iostat` и `mpstat` доступны обычно в пакете `sysstat` и могут отсутствовать по умолчанию. Примеры без установки: `df -h /`, `free -h`, `ps aux | head`.

## Сеть

`ip a` и `ip route` — интерфейсы и маршруты; `resolvectl status` — DNS при наличии systemd-resolved; `ss -tuln` — прослушиваемые порты; `ping -c 4 1.1.1.1` — тест сетевой доступности. В Debian сетевые настройки могут управляться NetworkManager, systemd-networkd либо ifupdown; способ конфигурации зависит от установки.

Административные изменения выполнять внутри отдельной VM и по возможности после создания снимка.
