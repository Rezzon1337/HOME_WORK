# Управление памятью в Linux

По презентации «Память.ppt».

Процессы используют **виртуальные адреса**, которые ядро и MMU отображают на физическую память. Разбиение на страницы позволяет разделять адресные пространства процессов, использовать copy-on-write, маппинг файлов и страничную подкачку. Преобразование адресов ускоряется TLB.

**Подкачка (swap)** позволяет вытеснять некоторые редко используемые страницы на диск, но активная подкачка обычно намного медленнее работы с ОЗУ. **Кеш** страниц помогает ускорять повторное чтение данных с диска. Команды `free -h`, `vmstat`, `cat /proc/meminfo` и `cat /proc/<PID>/maps` показывают разные стороны использования памяти.

`/proc/iomem` описывает физическую карту аппаратных диапазонов (часть может быть скрыта контейнером). `/proc/meminfo` показывает показатели памяти и swap. `/proc/<PID>/maps` — отображения виртуальной памяти конкретного процесса. `/proc/<PID>/mem` — бинарный интерфейс к его адресному пространству; чтение требует подходящих разрешений и корректного смещения, обычно ограничивается проверками ptrace.

Системные вызовы: `brk` и исторический `sbrk` изменяют границу области данных процесса (на практике аллокаторы часто используют и `mmap`); `mmap` создаёт отображение файла или памяти, `munmap` снимает его; `mlock` удерживает страницы в RAM по мере действия ограничений, `munlock` снимает блокировку.

Практические команды и безопасный пример чтения специально созданных процессов находятся в `memory/`.
