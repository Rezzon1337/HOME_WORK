# Работа с файлами и каталогами

Задание из слайда 19 `Работа с файлами.pptx`: повторить команды из презентации и продемонстрировать примеры. **Готовый демонстрационный скрипт**:

```bash
bash filesystem/file_ops_demo.sh | tee evidence/filesystem_demo.txt
```

Каждую команду он действительно выполняет в **свежем временном каталоге** (`mktemp -d`) и удаляет его после выхода. Команды с потенциальным удалением файлов не работают за пределами лабораторного каталога.

## Какие команды покрыты

- Каталоги: `pwd`, `cd`, `mkdir`, `mkdir -m`, `mkdir -p`, `ls`, `ls -F`, `ls -l`, `rmdir`, `rmdir -p`, `rm -r`.
- Файлы: `touch`, `cat` и перенаправление `>`, `more`, `cp`, `cp -r`, `mv`, `rm`, `rm -i`, `rm -v`.
- Обработка текста: `cut -c`, `cut -d`, `grep`, `grep -i`, `grep -c`, `grep -E`, базовые регулярные выражения.
- Поиск: `find -name`, `-type`, `-maxdepth`, `-mtime`, `-atime`, `-user`, `-group`, `-size`, `-exec`.

## Команды, требующие интерактивной работы

| Команда | Реальный способ выполнить вручную в терминале |
|---|---|
| `man ls` | открыть руководство, нажать `q` для выхода |
| `vi notes.txt` | открыть редактор, нажать `i`, написать текст, `Esc`, `:wq` |
| `ed notes.txt` | если `ed` установлен: `a` → строка → `.` → `w` → `q` |
| `cat > message.txt` | ввести текст, нажать Ctrl+D, затем `cat message.txt` |
| `more docs.txt` | пробел — следующая страница, `q` — выход |
| `rm -i filename` | подтвердить `y` или отклонить `n`; всегда внимательно проверять путь |

Они описаны отдельно, так как автоматический скрипт не может заменить взаимодействие с терминальным редактором.

## Неточности исходных слайдов и корректный вариант

1. `mv -r` — некорректный флаг в обычных Linux coreutils: перемещение каталога выполняется просто `mv dir newdir`. Рекурсивный флаг нужен `cp -r` или `rm -r`.
2. `grep 'get|put'` с базовыми регулярными выражениями ищет буквальный символ `|`; для альтернатив используйте `grep -E 'get|put'` или `egrep` (устаревающий синоним).
3. `find -size +500` означает более **500 блоков по 512 байт**, а не 500 байт. В демо `-size +500c` означает более 500 байт.
4. `find -exec rm {} \;` может безвозвратно удалять найденные файлы. Здесь вместо удаления безопасно используется `-exec wc -l {} \;`.
5. Команды `-mtime -3`, `-atime +3` требуют корректных знаков/пробелов и учитывают точность файловой системы.

Для снимков экрана откройте терминал в VM, запустите демонстрацию и сохраните **реальные** скриншоты выбранных блоков в `evidence/vm/`.
