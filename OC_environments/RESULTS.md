# Отчёт о подготовке и проверке домашней работы

## Основание

Использованы исходные задания из ZIP: «ДЗ скрипт.docx», «линукс.txt», «тз.txt», тематические презентации по GNU/Linux, администрированию, работе с файлами, управлению памятью, процессами и Bash. Пароли и иные доступы из текстового файла с учётными данными не переносились в проект и не применялись.

## Подготовленные материалы

- 20 отдельных исполняемых скриптов Bash — `bash/01_hello.sh` … `bash/20_words.sh`.
- Документация по разнице запуска `./`, `bash` и `sh`, правам, переменным, кодам завершения.
- Конспект GNU/Linux и схема структуры каталогов — `linux/01_gnu_linux_conspectus.md`, `assets/linux_tree.png`.
- Инструкция установки Debian в Oracle VirtualBox и раздел про снимки VM — `linux/02_virtualbox_debian_install.md`.
- Памятки по системному администрированию, процессам, памяти.
- Файловая практика и руководство по ручным редакторам.
- Проверка пользователей, смены владельцев, символических и цифровых прав.
- Сценарии `/proc` с двумя специально порождёнными процессами; читаются только их учебные буферы.

**Условие тестирования задания 09:** в тестовой Linux-среде отсутствовал отдельный исполняемый файл `bc`; для проверки скрипта команда `bc` предоставлялась встроенной реализацией **BusyBox bc** через временную символическую ссылку, не добавленную в проект. На обычной Debian рекомендуется `sudo apt install bc`. Это действительно выполненный тест с реализацией `bc`, а не синтетический ожидаемый вывод.

## Ограничения / чего не было

- Oracle VirtualBox с Debian на компьютере пользователя не запускался; установка описана инструкцией.
- Реальные снимки экрана **пользовательской** VM отсутствуют и не подделывались. Чек-лист: `evidence/README.md`.
- На GitHub пользователя ничего не загружено: для этого нужно подключение к его аккаунту и выбор репозитория.
- Файловые демонстрации `vi`, `ed`, `man`, `more` требуют терминального взаимодействия пользователя, поэтому представлены пошаговыми инструкциями; остальное выполнено автоматически.
