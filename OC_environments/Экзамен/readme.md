# Экзамен — Операционные системы и среды

Этот раздел репозитория [HOME_WORK](https://github.com/Rezzon1337/HOME_WORK) содержит материалы, относящиеся к экзамену по дисциплине **«Операционные системы и среды»**.

## О разделе

Папка `Экзамен/` выделена для экзаменационных материалов. Основной файл — **[ЭКЗАМЕН.docx](./%D0%AD%D0%9A%D0%97%D0%90%D0%9C%D0%95%D0%9D.docx)**. Остальные учебные материалы по дисциплине находятся в соседних разделах `OC_environments/`.

## Структура папки

```text
Экзамен/
├── ЭКЗАМЕН.docx  # экзаменационный документ
└── readme.md     # описание папки и полезные ссылки
```

## Как пользоваться

1. Откройте файл [ЭКЗАМЕН.docx](./%D0%AD%D0%9A%D0%97%D0%90%D0%9C%D0%95%D0%9D.docx).
2. При необходимости скачайте документ с GitHub и откройте его в Microsoft Word или LibreOffice Writer.
3. Для повторения тем курса используйте конспекты, скрипты и практические задания из разделов ниже.

> **Примечание:** в этой папке нет программ, которые нужно устанавливать или запускать. Экзаменационный материал представлен документом `.docx`.
