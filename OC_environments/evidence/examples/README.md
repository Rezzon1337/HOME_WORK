# Демонстрационные изображения терминала

Эти PNG-файлы **сгенерированы ИИ** и предназначены только для иллюстрации ожидаемого вида выполнения команд. На них показан условный пользователь `vboxuser`. Это **не реальные скриншоты установленной VM** и **не доказательство фактического выполнения заданий**.

Изображения соответствуют тематическим заданиям: установка/информация о системе, пользователи, права доступа, операции с файлами, `/proc/iomem`, `/proc/meminfo`, карты памяти, учебное чтение памяти и Bash.

Фактические журналы запуска в отдельной тестовой Linux-среде находятся в `../*.txt`; условия испытания и ограничения подробно описаны в `../../RESULTS.md`.
