# Подтверждения выполнения

- `bash_test_results.txt` — фактический вывод 20 проверок в текущей временной Linux-среде, **не** на личной VM. Для задачи 09 использовалась реализация BusyBox bc через временную ссылку (подробности в `../RESULTS.md`).
- `permissions_demo.txt` — фактическая проверка создания трёх учётных записей и смены владельцев в изолированной тестовой Linux-среде, **не** на личной VM.
- `filesystem_demo.txt` — фактический вывод повторения файловых команд в изолированном каталоге.
- `memory_demo.txt` — фактический вывод исследования текущей Linux-среды (показатели относятся к среде тестирования).
- `vm/` — сюда нужно добавить собственные скриншоты из Oracle VirtualBox по чек-листам ниже. **В момент подготовки проекта они отсутствуют**.

## Что снять на своей VM

1. Установка и загрузка Debian: экран VM и вывод `cat /etc/os-release`, `id`, `lsblk`.
2. Снимок `01-Clean-install` на вкладке Snapshots.
3. Выполнение `permissions/user_lab.sh` с `id`, `ls -l` и `stat`.
4. Демонстрация `bash/file_ops_demo.sh` или `filesystem/file_ops_demo.sh` с примерами команд.
5. Выполнение `/proc/iomem`, `/proc/meminfo`, `pgrep bash`, `maps`, `mem` — лучше с безопасным учебным `memory/read_mem_demo.py`.
6. Несколько Bash-задач со сложным вводом (`08`, `18`, `19`, `20`).

Рекомендуемые имена: `01-debian-installed.png`, `02-snapshot.png`, `03-users.png`, `04-permissions.png`, `05-file-commands.png`, `06-proc-iomem.png`, `07-proc-meminfo.png`, `08-processes-maps.png`, `09-processes-mem.png`, `10-bash-tasks.png`.

Ниже размещайте **только реальные снимки**, не указывайте, что демонстрационные результаты получены с вашей машины, если это не так. Не включайте пароли/токены/ключи SSH.
